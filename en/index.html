PawKemoViewer

An unofficial viewer that uses the public Pawchive API to browse posts, search for creators, and follow updates. Use the bottom menu on mobile or the sidebar on desktop.

Download ↓ Source code ↗

Features and how to use them

Find posts and creators

Browse posts from Home. In Creators, search by name, ID, or a supported service URL. Tap or click the creator’s name or avatar under a post title to see their page.

Open article links and original sites

Original post links can open the corresponding Pawchive post when it is found. The original-service buttons above the article use your system browser. The mobile in-app viewer shows the current URL.

Follow creators and save favorites

Sign in to Pawchive to sync followed creators and favorites. Open Following to check for updates and visit unread posts.

Control image usage

Post thumbnails can be cached and reused. Choose a cache size or enable data saver in Settings. Cached thumbnails remain available in data saver.

Languages and backups

Switch between Japanese and English. Place valid translation JSON files in the additional language folder and select Sync language folder. Export or restore a settings backup as JSON.

Supported devices and installation

Download the package for Windows, Linux, Apple silicon Mac, Android, or iPhone/iPad below. The iOS/iPadOS IPA requires signing before installation.
