# PawKemoViewer プライバシーポリシー

制定日: 2026-11-26
最終更新日: 2026-11-26

本プライバシーポリシーは、PawKemoViewer(以下「本アプリ」)における利用者情報の取扱いを定めるものです。

## 1. 取得・保存する情報

本アプリは、次の情報を**端末内にのみ**保存します。

- 設定(テーマ、表示モード、言語、通信タイムアウト等)
- フォロー、お気に入り、既読状態
- 認証情報(利用者が入力した pawchive のセッションキー)
- 投稿のサムネイル・アイコン等のキャッシュ
- アプリの動作ログ(端末内)
- 18 歳以上の確認状態

本アプリは、氏名、住所、電話番号、位置情報、連絡先、広告 ID を取得しません。アクセス解析・クラッシュ解析・広告 SDK は組み込んでいません。

## 2. 利用目的

保存した情報は、次の目的で利用します。

1. 本アプリの機能提供(投稿・クリエイター・お気に入り・フォローの表示)
2. 設定の保持と復元
3. 不具合の調査(利用者が任意に共有した場合のみ)

## 3. 外部への送信

本アプリは、機能提供のため次の外部サービスと通信します。

- **pawchive.pw**: API および画像の取得。認証情報はこの通信にのみ使用します。
- **外部ページ**: 利用者が外部ページを開いた場合、実オリジンの WebView で表示します。
- **GitHub**: 利用規約・プライバシーポリシーへのリンク、更新確認等。

通信は HTTPS 等の暗号化された経路で行われます。開発者が利用者の情報を収集・保存するサーバーはありません。

## 4. 第三者提供

本アプリは、法令に基づく場合を除き、利用者の情報を第三者へ提供しません。ただし、前項の通信先サービスには、その機能の提供に必要な範囲で情報が送信されます。各サービスの取扱いは、それぞれのプライバシーポリシーに従います。

## 5. ログ

本アプリは、端末内に動作ログを保存します。認証情報(セッションキー)、Cookie、Authorization ヘッダー等の機密値はログに記録しない設計です。利用者がログを共有する場合は、内容を確認してから行ってください。

## 6. 保存期間と削除

1. 保存した情報は、利用者が削除するか、本アプリをアンインストールするまで端末内に保持されます。
2. 設定画面からデータを初期化・削除できます。
3. バックアップ機能を利用した場合、バックアップファイルは利用者の選んだ場所に保存されます。認証情報はバックアップに含めない設計です。

## 7. 安全管理

本アプリは、認証情報の取扱いに注意し、ログへの出力やクリップボードへのコピーを避ける等の安全管理措置を講じます。ただし、端末自体の安全性(OS の更新、画面ロック等)は利用者の責任です。

## 8. 未成年者の利用

本アプリは 18 歳以上の方のみを対象としています。18 歳未満の方は利用しないでください。

## 9. 開示・訂正・削除等の請求

本アプリは開発者のサーバーに利用者情報を保存しないため、開示等の請求の対象となる情報は原則として端末内に限られます。ご不明な点は下記までご連絡ください。
