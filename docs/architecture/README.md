移行は小さく進め、既存動作を保つ。プラットフォーム固有の処理は型付き契約の背後に置き、ユースケースは処理の流れ、リポジトリはデータアクセスを担う。ドメインはフレームワークから独立させ、具体的な用途がある場合に抽象化する。共有する引き継ぎは日本語で記録する。
