# 画面構成

## 画面とナビゲーション

主な画面はホーム、クリエイター一覧、クリエイター詳細、投稿詳細、フォロー / お気に入り、設定、ログインです。ルートはハッシュベースで、`App` がルート変更、設定変更、キーボード、ネイティブの戻る操作を購読します。

- **デスクトップ**: 左のナビゲーションレールを使用します。
- **モバイル**: 画面下端のナビゲーションを使用し、セーフエリアをバー内部の余白で確保します。
- **クリエイター詳細・ログイン**: 主ナビゲーションを隠し、戻る用のヘッダーを表示します。
- **投稿詳細**: 「戻る」と「ホーム」を表示します。前後投稿への移動では履歴を置き換えるため、一覧へ戻るには「戻る」または「ホーム」を使います。

## レイアウトモード

設定 `layoutMode` は `auto` / `desktop` / `mobile` です。

- `auto`: デスクトップ相当の UA では 768 CSS px 以上でレール、それ未満では下部ナビゲーション。
- モバイル相当の UA: `auto` でも下部ナビゲーション。
- 明示選択: 画面幅や UA に関係なく指定したレイアウトを使用。

レイアウトは表示専用で、ストレージ、API、ライフサイクルのプラットフォームファミリーは変更しません。ネイティブ iOS / iPadOS の判定も表示とは別に、実行環境とネイティブプラグインの対応状況から行います。

## ホーム

- 検索語、サービス絞り込み、履歴、グリッド / リストを一つの操作ツリーにまとめます。
- デスクトップとモバイルの切り替え後も、フォーカス、入力中の文字、読み込み済み結果を保持します。
- 検索は 3 文字以上。URL の貼り付けを含め、入力をそのまま検索語として送信します。
- 無限スクロールの判定は scroll / resize を `requestAnimationFrame` で集約します。

## クリエイターと投稿

- クリエイター一覧は索引を段階的に表示し、更新日・人気・名前で並べ替えられます。
- FANBOX / Patreon / pawchive のクリエイター URL を認識し、FANBOX 投稿 URL は対応するクリエイターを検索して「この投稿を開く」を表示します。
- 投稿カードと投稿詳細で共通のファイル選別を使い、FANBOX `cover.jpeg` の除外設定を一覧にも適用します。
- 投稿詳細はサムネイルを先に表示し、必要に応じて本体を読み込みます。
- 長いタイトルは画面幅で折り返し、flex 子要素の `min-width: 0` で横はみ出しを防ぎます。

## 一括画像保存の UI

- 投稿詳細の「画像を一括保存」から、本文・添付・外部リンクを選択して開始します。
- アプリ全体の右下ボタンで進捗（`n/N`）、完了、失敗件数を表示します。
- ボタンを押すと、実行中は中止、完了後は結果と保存先を確認できます。
- 状態は `src/download-status.ts` の共有ストアで管理し、投稿画面を離れても保持します。
- 外部ページのビューには、表示中 DOM の画像を選ぶチェック式 UI を重ねます。デスクトップは
  専用ウィンドウに差し込んだツールバーから開きます。

仕様の詳細は[一括画像保存](../features/image-download.md)を参照してください。

## キーボード（デスクトップ）

| キー | 操作 |
|---|---|
| `H` | ホーム |
| `C` | クリエイター |
| `F` | フォロー / お気に入り |
| `S` | 設定 |
| `/` または `Ctrl/Cmd+K` | 検索欄へフォーカス |
| `Esc` | 戻る・閉じる |

入力中など、ショートカットを無効化すべき状況では画面側で判定します。

## 表示の確認

- 320 / 390 / 768 / 1024 px での折り返しと横はみ出し
- レイアウト切り替え後のフォーカス・入力・読み込み結果の保持
- 下部ナビのセーフエリアとスクロール
- 設定項目の縦積み、長いパスの折り返し
- 実機の WebView、物理戻る、横向き、iOS のセーフエリア

ブラウザーのスモーク確認と実機確認は別です。手順は[検証ガイド](../verification.md)を参照してください。
