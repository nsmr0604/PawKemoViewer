# 変更履歴

リリースごとの主な変更点です。詳細な設計・検証の記録は [開発状況](STATUS.md) と
[設計資料](architecture/README.md) にあります。

| バージョン | 主な変更 |
|---|---|
| **0.5.8** | 投稿の本文・添付・外部リンク先の画像をまとめて保存 (保存前に対象を選択、右下の常時表示ボタンで進捗、外部ページはチェック式)。外部ページのビューからも画像を保存。ヘッダー・SNS アバターを除外。UA を端末既定にし選択式に。投稿の前後移動後にホームへ戻れる導線。開発版のバージョンを `x.y.z+<run>` に |
| **0.5.7** | 言語ファイルの上書き・削除確認を修正し、言語フォルダー同期と診断操作を分離。投稿のクリエイター表示と外部リンクを改善。iOS の JSON 選択をコピー取り込みに変更し、iPadOS のデスクトップ UA 判定を修正 |
| 0.5.6 | 言語ファイル検査の共通化、投稿サムネイルの端末キャッシュ、元記事リンクのアプリ内解決、Android のファイル選択スモークテスト、言語・ファイル操作ガイドの更新 |
| **0.5.5** | 投稿本文の外部リンクを、元記事 URL を Referer にした**実オリジンのネイティブビュー**で開く (Android / iOS)。pkv の Referer 導出・通信制御の修正を含む |
| 0.5.3 | pkv プロキシの Referer を service / creatorId / postId から導出。外部ホストも投稿コンテキストで中継。OS 別 URL 形式、SSRF / リダイレクト検査、タイムアウト、サイズ上限、ワーカー化を追加 (配布は 0.5.5) |
| 0.5.2 | 言語ファイルとバックアップの JSON を OS のファイル選択で共通化。モバイルの標準保存先をアプリの書類領域に統一。iOS を Document Based Apps に対応 |
| 0.5.1 | 0.5.0 基盤を main に統合してリリース。PC / Android / iOS/iPadOS の 9 アセットを公開 |
| 0.5.0 | プラットフォーム共通基盤 (domain / application / infrastructure / platform)。OS 別ストレージ、言語ファイルの取り込み・書き出し、デスクトップ / モバイルの画面分離、依存境界チェック |
| 0.4.1 | アイコンをビルド時生成に変更。デバッグ版の版表記に commit を表示 |
| 0.4.0 | UX/UI 刷新、通信・描画の効率化、フォロー新着 (直近 7 日) と既読キャッシュ、お気に入り投稿の表示修正 |
| 0.3.2 | Android の戻るキー対応 (公式 `onBackButtonPress`)、正式リリース |
| 0.3.1 | pkv の対象を FANBOX / Patreon に限定 (pawchive 本体は直接通信)、FANBOX cover.jpeg 除外、UI 調整 |
| 0.3.0 | 内部キー・identifier・crate 名を全面改名 (0.2.x からの引継ぎはバックアップ経由) |
| 0.2.3 | 改訂履歴 404 の扱い、pkv プロキシ設定、デバッグ診断の拡充 |
| 0.2.2 | Android 署名を標準 debug.keystore 手順に統一 |
| 0.2.1 | 改訂履歴と投稿版の切り替え |
| 0.2.0 | フォローをアカウント同期へ統合 (pawchive を正とする) |
| 0.1.10 | バックアップ、通信タイムアウト、検索履歴、前後スワイプ |
| 0.1.9 | プラットフォーム分離、ナビゲーションレール、レイアウトモード、リスト表示、低通信モード、クリップボード URL 検出 |
| 0.1.8 | ログ診断、エラー表示の判別、テーマ、設定画面の構造化、キャッシュ表示、ライトボックス |
| 0.1.4〜0.1.7 | クリエイター検索索引 (パック形式、ローマ字クエリ) |
| 0.1.3 | CI 成功・実機確認の起点 |

- 0.5.4 は使用していません。
- デバッグビルドは `debug-latest` プレリリースに随時更新されます。
- 正式リリースは `pawkemoviewer-v{VER}` タグで作成します。
