# PawKemoViewer

An unofficial viewer that uses the pawchive.pw API to browse posts, creators, and favorites.

## Features

- Post list (grid / list, infinite scroll, filter by source service)
- Creator search, profiles, post lists, follows
- Post detail (content, images/videos, comments, revisions, previous/next post)
- Thumbnail-first loading, low-data mode, file-list mode
- Save selected images from posts, attachments, and external pages (personal use only)
- Display external pages at their real origin
- Follows, favorites, read state
- Backup, logs, Japanese / English, dark / light themes

## Privacy

- **The developer and distributors do not collect any personal information.**
- No analytics, advertising, crash-reporting, or tracking SDKs.
- Settings, follows, favorites, read state, session keys, and caches are stored only on your device.
- Credentials and search terms are used only for communication with pawchive.pw to provide the app's features.
