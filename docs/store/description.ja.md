# PawKemoViewer

pawchive.pw の公式 API を利用して、投稿・クリエイター・お気に入りを閲覧する非公式ビューアです。

## 主な機能

- 投稿一覧(グリッド / リスト、無限スクロール、投稿元サービスでの絞り込み)
- クリエイター検索、プロフィール、投稿一覧、フォロー
- 投稿詳細(本文、画像・動画、コメント、改訂履歴、前後の投稿への移動)
- サムネイル優先表示、低通信モード、投稿ファイルのリスト表示
- 投稿・添付・外部ページの画像を選んで保存(私的利用の範囲)
- 外部ページを実オリジンのまま表示
- フォロー / お気に入り、既読管理
- バックアップ、ログ、日本語 / 英語、ダーク / ライト

## プライバシー

- **開発者・配布者は、利用者の個人情報を一切収集しません。**
- アクセス解析、広告、クラッシュ収集、トラッキング SDK は組み込んでいません。
- 設定・フォロー・お気に入り・既読・セッションキー・キャッシュは端末内にのみ保存されます。
- 認証情報や検索語は、機能提供のため pawchive.pw への通信にのみ使用されます。
