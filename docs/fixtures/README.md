# 実機検証用フィクスチャ

言語ファイルの取り込み・追加フォルダー・入力拒否を確認するための小さな JSON です。製品の翻訳リソースではありません。

| ファイル | 期待する結果 |
|---|---|
| `qaa.json` | アプリ専用領域への取り込み成功。表示名は `QA Import` |
| `qab.json` | 追加フォルダーから同期成功。表示名は `QA Folder` |
| `qac.json` | `nav.home` が数値なので拒否。言語一覧は変わらない |

端末に `qaa` / `qab` / `qac` が既にある場合は、未使用の言語コードへファイル名を変更します。製品版で確認できるのは `qab.json` の追加フォルダー同期までです。`qaa.json` の取り込み、`qac.json` のピッカー選択、キャンセル、書き出しは、フロントと Rust の診断フラグを両方有効にした診断ビルドで確認してください。手順は[検証ガイド](../verification.md#言語ファイルの実機確認)を参照してください。
