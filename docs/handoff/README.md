# 引継ぎ資料

[開発状況](../STATUS.md)、[開発ガイド](../DEVELOPMENT.md)、[設計資料](../architecture/README.md) にあります。
このディレクトリは「次に作業する人・エージェントが最初に読むもの」です。

## 引継ぎを書くときのルール

- 日本語で書く。コマンド・パス・識別子・エラーの原文はそのまま引用する
- 日付・対象バージョン・コミットを先頭に書く
- 「決まったこと」「未完了」「次の作業」「検証した証拠」を分けて書く
- 仕様そのものは `docs/` の該当資料に書き、ここには経緯と申し送りだけを残す
- 秘密情報 (パスワード・鍵・セッション) は書かない
