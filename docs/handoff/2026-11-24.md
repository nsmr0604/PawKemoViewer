# 引継ぎ (2026-11-24 / 0.5.7)

対象: main `0.5.7`。最終更新: 2026-11-24。

## 決まったこと

- 外部ページ (reCAPTCHA を含むサイト) は pkv プロキシでは表示できないため、
  Android / iOS では **実オリジンのネイティブビューに Referer を付けて開く**方針にした
  (`src-tauri/plugins/external-view`、`open_external_page`)。デスクトップは pkv のまま
- pkv の Referer は service / creatorId / postId から導出する
  (`src/domain/post-referer.ts`)。許可する Referer は fanbox.cc / patreon.com のみ
- 投稿本文内の fanbox / patreon の投稿 URL は、対応する pawchive の投稿へアプリ内で遷移する
  (`src/original-post-link.ts` / `src/original-post-navigation.ts`)
- ドキュメントは日本語を正とする。Wiki は利用者向けに単体で完結させ、`docs/` を参照しない
- 引継ぎは `docs/handoff/` に分離する

## 一括画像ダウンロード (2026-11-25 追加)

- 投稿詳細の「画像を一括保存」から、本文・添付 (file / attachments)・外部リンク先の
  画像をまとめて保存できる。保存前に件数を見て対象を選ぶ
- 保存先: デスクトップ `Downloads/PawKemoView/<クリエイター名>`、
  モバイル `Documents/Downloads/<クリエイター名>` (不可なら Documents → アプリデータ)
- 取得は Rust 側。ミラーはブラウザ相当のヘッダーが必要 (UA + Referer だけでは 403)
- 検証: Windows 開発ビルド (添付 5 + 外部 2 = 7 件保存、対象解除で 0 件、失敗理由表示)、
  Android (Redmi K20 Pro) で 5 件保存と保存先を実機確認。iOS は未確認
- 残り: iOS 実機確認、ヘッダー・SNS アバターの除外、サイズ違いの重複排除、
  実行をまたいだ重複スキップ
