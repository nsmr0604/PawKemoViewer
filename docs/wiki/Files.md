# バックアップとログ

## バックアップを保存する

設定の **バックアップ** から書き出します。設定、フォロー、既読が `pawkemoviewer-backup.json` に入ります。設定にはログイン時のセッションキーが含まれる場合があるため、バックアップの共有先には注意してください。

- Android・iOS では **標準フォルダーに保存** すると、`Backups` 内の標準バックアップを更新します。別名や別の場所に保管するには **別の保存先を選ぶ** を使います。
- デスクトップでは **バックアップの保存先を選ぶ** から保存場所を指定します。

## バックアップを復元する

**標準バックアップを開く** または **別のバックアップを開く** でファイルを選び、アプリの確認ダイアログで復元を確定します。デスクトップでは **バックアップファイルを開く** を使います。詳細操作から JSON の貼り付けによる復元もできます。ファイルの上限は 5 MiB です。

## 標準フォルダーとログ

| 環境 | 標準フォルダー |
|---|---|
| Android | `Android/data/com.nsmr0604.pawkemoviewer/files/Documents` |
| iOS・iPadOS | ファイル → このiPhone内／このiPad内 → PawKemoViewer |

バックアップは `Backups`、追加の言語ファイルは `Languages` に保存します。
