# バックアップ、ログ、標準フォルダー

## バックアップを保存する

設定 → バックアップから書き出します。`pawkemoviewer-backup.json` には次が含まれます。

- 設定
- フォロー
- 既読

設定にはログイン時の session が含まれる場合があるため、バックアップは機密ファイルです。共有先に注意してください。

- Android / iOS: **標準フォルダーに保存**で `Backups` 内の標準ファイルを更新。別名や別の場所は **別の保存先を選ぶ**。
- デスクトップ: **バックアップの保存先を選ぶ**から保存場所を指定。

## バックアップを復元する

**標準バックアップを開く**、**別のバックアップを開く**、またはパネル内の **バックアップ JSON** へ貼り付けて復元します。

- サイズ上限は 5 MiB。
- 復元すると、現在のフォロー・既読・設定を上書きします。必要なら先にバックアップを保存してください。
- `accountId` と `userAgentMode` はバックアップから復元されません。
- クリエイター索引、投稿サムネイル、アイコン、検索履歴、ログ、言語ファイルはバックアップ対象外です。

## 標準フォルダー

| 環境 | 標準フォルダー |
|---|---|
| Android | `Android/data/com.nsmr0604.pawkemoviewer/files/Documents` |
| iOS / iPadOS | ファイル → このiPhone内 / このiPad内 → PawKemoViewer |
| Windows / macOS / Linux | バックアップ / ログは選択した保存先。追加言語は `Documents/Pawchive/languages` |

| 用途 | サブフォルダー |
|---|---|
| 標準バックアップ | `Backups` |
| ログの書き出し | `Logs` |
| 追加言語 | `Languages` |
| 一括画像 | デスクトップは `Downloads/PawKemoView/<クリエイター名>`、モバイルは `Documents/Downloads/<クリエイター名>` |

Android では debug / locale_test パッケージによりアプリ ID 部分が変わります。

## ログ

設定 → 情報 / 開発・診断からログを確認・保存できます。

- 製品版: エラー系のログを保存できます。
- 診断ビルド: API、pkv、外部ページなどの詳細ログを保存できます。
- iOS の診断ビルドは `Logs/external-page-diagnostic.txt` に外部ページの診断を書き出します。

ログには認証情報や個人情報が残る場合があります。共有前に内容を確認し、session や Cookie を載せないでください。

## 言語ファイル

製品版では、追加フォルダーへ置いた JSON の読み込みと言語フォルダーの同期が使えます。任意ファイルの取り込み、アプリ専用辞書の追加・上書き・削除、ピッカー書き出しは診断ビルド専用です。

詳しくは[表示言語と翻訳ファイル](Languages)を参照してください。
