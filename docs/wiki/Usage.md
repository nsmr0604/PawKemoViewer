# 画面と使い方

## 画面の構成

- **PC**: 左のナビゲーションからホーム / クリエイター / フォロー / 設定を切り替えます。
- **モバイル**: 画面下のナビゲーションで切り替えます。
- 設定 → 表示 → レイアウトモードで、自動 / デスクトップ / モバイルを選べます。
- アカウントボタンは、未ログインならログインへ、ログイン中は確認後にログアウトします。

### キーボード（PC）

| キー | 操作 |
|---|---|
| `H` | ホーム |
| `C` | クリエイター |
| `F` | フォロー / お気に入り |
| `S` | 設定 |
| `/` または `Ctrl/Cmd+K` | 検索欄へ移動 |
| `Esc` | 戻る・閉じる |

入力中はショートカットが無効になります。

## ホーム

- 検索語は 3 文字以上。検索履歴はチップから再利用できます。
- サービス（すべて / fanbox / patreon）で絞り込みます。
- 新着投稿は 50 件ずつの無限スクロールです。
- グリッド / リストを切り替えられます。
- AI 投稿の除外は設定 → 投稿表示で変更できます。
- pawchive の投稿 / クリエイター URL を貼り付けると、検索語として送信されます。

## クリエイター

- 名前 / ID / クリエイター slug で検索します。
- 更新日・人気・名前で並べ替えられます。
- 一覧は 60 件ずつ段階的に表示します。
- クリエイターを開くと、プロフィール、バナー、タグ、投稿一覧を表示します。
- ★ フォローでフォロー状態を切り替えます。ログイン中は pawchive と同期します。
- 各サービスと pawchive のクリエイター URL を認識します。
- 各サービスの投稿 URL は対応するクリエイターを検索し、「この投稿を開く」を表示します。

## 投稿詳細

- タイトルの下のクリエイター名 / アイコンから、そのクリエイターのページへ移動します。
- 本文、添付画像・動画、埋め込み、タグ、取得日時を表示します。
- サムネイルを先に読み込み、「元画像を一括読み込み」で本体へ切り替えられます。
- 省データのリスト表示では、必要なファイルだけを読み込みます。
- タグのチップから、そのクリエイターのタグ絞り込みへ移動します。
- 「← 前」「次 →」、左右スワイプ、矢印キーで前後の投稿へ移動します。
- コメントと改訂履歴を表示し、過去の版へ切り替えられます。
- ログイン中は ☆ で投稿をお気に入りに追加 / 解除できます。
- 「サイトで開く」は pawchive、「元サービスで開く」は元サービスを OS のブラウザで開きます。
- 上部の「戻る」と「ホーム」から一覧へ戻れます。前後移動では履歴を積まないため、「戻る」で一覧へ戻ります。

### 本文内のリンク

- 各サービスの元記事投稿 URL は、対応する pawchive 投稿へアプリ内で移動します。見つからない場合は元記事を開く導線を表示します。
- その他の外部サイトは、元記事 URL を Referer にして実オリジンのまま開きます（全 OS）。Android / iOS はネイティブビュー、デスクトップは専用ウィンドウです。
- どちらも画面上部に現在の URL を表示するバーがあり、「戻る」「画像を保存」「閉じる」を使えます。「閉じる」または戻る操作で投稿へ復帰します。

## 一括画像保存

投稿詳細の **画像を一括保存** から、次を選んで保存できます。

- 本文の画像
- 添付画像
- 外部リンク先の画像

既定はすべて選択です。0 件の項目は選べません。保存すると、右下のボタンに `n/N` の進捗が出ます。押すと中止、結果、保存先を確認できます。

- 成功件数、失敗件数、最初の 5 件までの失敗理由を表示します。
- 1 件失敗しても後続を継続します。
- デスクトップ: `Downloads/PawKemoView/<クリエイター名>`
- Android 10 以降: 端末の `Download/PawKemoViewer/<クリエイター名>`（Android 9 以下は `Documents/Downloads/<クリエイター名>`）
- iOS: `Documents/Downloads/<クリエイター名>`（ファイル App の PawKemoViewer 内）
- ファイル名は `001_<元の名前>`。衝突時は `-2`、`-3` を付けます。
- サムネイルだけの投稿で元画像が 404 の場合は保存に失敗します。失敗理由で確認できます。

### 外部ページの画像を保存（全 OS）

1. 外部ページを表示し、必要な操作や CAPTCHA を済ませます。
2. ツールバーの **画像を保存** を押します。
3. サムネイルのグリッドから、丸チェックで画像を選びます。
4. **すべて選択 / すべて解除**、**保存 (n)**、✕ を操作します。
5. アプリへ戻り、通常の一括保存として続きます。

デスクトップは専用ウィンドウが閉じてアプリへ戻ります。

## フォローとお気に入り

- **フォロー**: フォロー中のクリエイターと新着を確認します。既読、全件既読、解除、並べ替えができます。
- **投稿お気に入り**: アカウントのお気に入り投稿を一覧・並べ替えします。
- 自動新着チェックには 5 分のクールダウンがあります。
- NEW は公開日時または取得日時が直近 7 日以内の投稿です。

## 表示の節約

- 設定 → 通信 → **低通信モード**: 新たな画像の取得を抑え、保存済みサムネイルを表示します。
- 設定 → 投稿表示 → **省データのリスト表示**: 投稿内ファイルを名前一覧にし、必要なものだけ読み込みます。
- 設定 → キャッシュで、投稿サムネイルの保存上限を変更できます。
