# 画面と使い方

## 画面の構成

以下の画面例は 0.5.7 の製品版UIをサンプルデータで撮影したものです。[紹介サイトの画面ギャラリー]({{PAGES_URL}}/ja/#screens) では PC・モバイルとライト・ダークを切り替えられます。

- **PC**: 左のナビゲーションから ホーム / クリエイター / フォロー / 設定 を切り替えます。
- **モバイル**: 画面下のナビゲーションで切り替えます。
- 設定 → 表示 → レイアウトモード で「自動 / デスクトップ / モバイル」を選べます。
- 右上の「アカウント」からログイン状態とアカウント設定を確認できます。

### キーボード (PC)

- `H` ホーム / `C` クリエイター / `F` フォロー / `S` 設定
- `/` 検索欄へ移動
- `Esc` 戻る・閉じる

## ホーム (投稿を探す)

![PC版のホーム。左のナビゲーションと投稿グリッド]({{PAGES_URL}}/assets/screens/ja-light-home-desktop.png)

- 検索欄に 3 文字以上を入力して検索します。検索履歴はチップから再利用できます。
- サービス (すべて / FANBOX / Patreon) で絞り込めます。
- 「新着投稿」は無限スクロールです。グリッド / リストを切り替えられます。
- 設定 → 投稿表示 の「AI 投稿を除外」を有効にすると、AI 分類の投稿を一覧と検索から除外します。
- URL を貼り付けると、投稿・クリエイターを直接開けます。

## クリエイター

![クリエイター名を入力して絞り込んだ検索画面]({{PAGES_URL}}/assets/screens/ja-light-creators-desktop.png)

- 名前 / ID / URL で検索します。更新日・人気・名前で並べ替えられます。
- クリエイターを開くと、プロフィール・タグ・告知・投稿一覧を表示します。
- ★ フォローでフォロー状態を切り替えます。ログイン中はアカウントと同期します。
- 投稿一覧は 60 件ずつ段階的に表示します (約 10 万件の索引に対応)。

## 投稿詳細

![モバイル版の投稿詳細。タイトル下のクリエイターボタンとサイトを開く操作]({{PAGES_URL}}/assets/screens/ja-light-detail-mobile.png)

- タイトルの下にあるクリエイターのアイコンまたは名前を押すと、そのクリエイターのページへ移動します。

- 本文の下に画像・動画を表示します。サムネイルを先に読み込み、
  「元画像を一括読み込み」で本体へ切り替えられます。
- タグのチップから同じタグの投稿へ絞り込めます。
- 「← 前」「次 →」で前後の投稿へ移動します。モバイルでは左右スワイプでも移動できます。
- コメント、改訂履歴 (版の切り替え)、取得日時を表示します。
- ☆ お気に入りで投稿をお気に入りに追加・解除できます (ログイン時)。
- 「サイトで開く」は Pawchive、「fanbox / patreon で開く」は元サービスの投稿を OS のブラウザで開きます。

### 本文内のリンク

- **元記事の投稿リンク** (fanbox / patreon の投稿 URL) は、対応する pawchive の投稿へ
  アプリ内で移動します。見つからない場合は「元記事を開く」が表示されます。
- **外部サイトのリンク** は、Android / iOS では外部ページビューで開きます。
- 外部ページビューの上部には現在の URL が表示されます。「閉じる」または戻る操作で投稿へ戻ります。
- 投稿詳細の上部には「戻る」と「ホーム」があります。前後の投稿へ移動した後でも、
  「ホーム」から一覧へすぐ戻れます。
- 外部ページビューの **「画像を保存」** で、表示中のページの画像をサムネイルのチェック式で選び、
  選んだ画像だけを保存できます。保存はアプリ内で続き、右下の常時表示ボタンに
  `3/12` のような進み具合が出ます。押すと中止や結果の確認ができます。

## フォロー (お気に入り)

![フォロー中のクリエイターと最新投稿の一覧]({{PAGES_URL}}/assets/screens/ja-light-following-desktop.png)

- 「フォロー」タブでフォロー中のクリエイターと新着を確認します。
- 投稿のお気に入りは「お気に入り」タブで一覧・並べ替えができます。
- 新着チェックは 5 分間隔で、通信を抑えるクールダウンがあります。
- NEW 表示は直近 7 日以内の投稿が対象です。「既読」にすると次回から表示されません。

## 表示の節約

- 設定 → 投稿表示 → **低通信モード**: 新たな画像の取得を抑えます。保存済みの投稿サムネイルは表示できます。
- 設定 → 投稿表示 → **省データのリスト表示**: 投稿内のファイルを名前の一覧で表示し、
  必要なものだけ読み込みます。
- 一覧のサムネイルは端末にキャッシュされ、再表示時は通信しません。
