# 表示言語と翻訳ファイル

設定 → 言語・翻訳ファイル → **言語 / Language** で日本語、English、追加した言語を選べます。切り替えはすぐに反映されます。

## 言語ファイルを追加する

1. UTF-8 の JSON を `es.json` や `zh-Hant.json` の名前で保存します。
2. 設定に表示される **追加の言語フォルダー** に置きます。
3. **言語フォルダーを同期** を押します。
4. **言語 / Language** から追加した言語を選びます。

## 追加の言語フォルダー

| 環境 | フォルダー |
|---|---|
| Windows / macOS / Linux | OS のドキュメントフォルダー内の `Pawchive/languages` |
| Android | `Android/data/com.nsmr0604.pawkemoviewer/files/Documents/Languages` |
| iOS / iPadOS | ファイル → このiPhone内 / このiPad内 → PawKemoViewer → Languages |

Android では端末のファイル管理アプリから `Android/data` にアクセスできない場合があります。

**言語フォルダーを同期** は、フォルダーの有効な JSON を読み直します。選択中の言語にアプリ専用ファイルがある場合は、同名ファイルがフォルダーにないときだけ書き出します。

## 上書きの順番

同じ言語コードでは、次の順で上書きします。

1. 同梱辞書
2. アプリ専用ファイル
3. 追加フォルダーのファイル

`ja.json` も差し替えられます。選択した言語にない文言は日本語で表示されます。未知の言語や読込失敗も日本語へ戻ります。

## JSON の書き方

`locale.name` に一覧の表示名を指定し、翻訳を 1 件以上追加します。キーは[日本語辞書]({{REPOSITORY_URL}}/blob/{{DEFAULT_BRANCH}}/src/locales/ja.json)と同じフラットなドット区切りで、値は空でない文字列にします。上限は 1 MiB です。

```json
{
  "locale.name": "Español",
  "nav.home": "Inicio",
  "settings.backupOpenOther": "Abrir otra copia de seguridad",
  "settings.backupDefaultDesc": "Guarda la copia en Backups dentro de {{path}}."
}
```

- キーは日本語辞書に存在するものだけ使えます。
- `{{path}}` のような差し込み変数は、日本語原文と同じ名前を使います。訳文内で順番を入れ替えられます。
- キーの誤記、空文字、差し込み変数の不足・追加は設定画面に理由として表示されます。
- 使用する言語だけの部分翻訳も取り込めます。
- 言語コードは英字 2〜3 文字で始まり、その後に英数字 2〜8 文字の `-` 区切りを最大 2 つ使えます。例: `es`、`pt-BR`、`zh-Hant-TW`。

## 診断ビルド専用の操作

診断ビルドの設定 → 開発・診断 → 言語ファイルの診断では、次もできます。

- 任意の JSON ファイルを選んで取り込む
- アプリ専用辞書を追加・上書き・削除する
- 選択した言語をシステムのファイル選択から書き出す
- 重複する言語コードの上書きを確認する

製品版で開発項目を表示しても、これらの Full 診断機能は使えません。

## 追加した言語が表示されない

- ファイル名が言語コードになっているか確認します。
- `locale.name` があり、JSON として正しいか確認します。
- 追加フォルダーに置き、**言語フォルダーを同期** を押します。
- エラー表示されたキーと変数を修正します。
