# 言語 (Languages) / Languages

PawKemoViewer は表示言語を切り替えられます。設定 → 表示 → 言語 から選択します (再起動不要)。

## 同梱の言語

- 日本語 (既定)
- English

## 言語を追加する (利用者)

言語ファイル (JSON) を貼り付けて追加できます。

1. 設定 → 表示 → 言語 → **言語を追加** を開く
2. **言語コード** を入力 (例: `es`、`zh-Hant`)
3. **言語ファイル (JSON)** に JSON を貼り付け、**追加**

追加後は言語の一覧に表示されます。削除は同じ画面の **削除** から行えます。

### 言語ファイルの形式

- 形式は JSON で、キーと値はどちらも文字列です
- 必須キー `locale.name`: 一覧に表示する名前 (例: `"Español"`)
- 値に無いキーは **日本語で表示** されます (部分的な翻訳でも使えます)
- 文字列以外の値は無視されます
- サイズは 1 MiB までです

例:

```json
{
  "locale.name": "Español",
  "settings.title": "Ajustes",
  "settings.save": "Guardar"
}
```

キー名は日本語版 (同梱の `ja.json`) と同じ名前を使います。

### 言語コード

- 英字 2〜3 文字で始め、`-` で区切った英数字を続けられます (例: `es`、`pt-BR`、`zh-Hant`、`zh-Hant-TW`)

## 日本語を書き換える

同じコードの言語ファイルを追加すると、同梱の日本語を上書きできます (`ja`)。上書きしていないキーは同梱の日本語のまま表示されます。

## 注意

- 言語ファイルが読み込めなかった場合は、日本語で表示されます
- 不正な言語ファイル (JSON として読めない、`locale.name` が無い) は追加されません
- Windows では言語ファイルは `%APPDATA%\com.nsmr0604.pawkemoviewer\locales` に保存されます
