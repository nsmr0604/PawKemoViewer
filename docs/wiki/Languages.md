# 言語 (Languages) / Languages

PawKemoViewer は表示言語を切り替えられます。設定 → 表示 → 言語 から選択します (再起動不要)。

## 同梱の言語

- 日本語 (既定)
- English

## 言語を追加する (利用者)

設定 → 表示 の「言語ファイル」から、JSON ファイルを取り込むか、追加フォルダーへ置きます。

1. 設定 → 表示 → **言語ファイルを取り込む** → **言語ファイルを選ぶ**
2. JSON を選択すると、検証後にアプリ専用領域へコピーされます
3. 言語の一覧に表示されない場合は **言語を再読み込み** を押します

追加フォルダーを使う場合は、**追加の言語フォルダー** に表示されるパスへ JSON を置き、
**言語を再読み込み** を押します。

- Android: `Android/data/<アプリ ID>/files/Documents/Languages`
- iOS / iPadOS: Files の `PawKemoViewer/Documents/Languages`
- デスクトップ: アプリデータの `locales`

書き出しは **追加フォルダーに保存**、または **別の保存先を選ぶ** から行えます。

### 言語ファイルの形式

- JSON で、キーと値は文字列
- 必須キー `locale.name`: 一覧に表示する名前 (例: `"Español"`)
- 値に無いキーは **日本語で表示** (部分的な翻訳でも使える)
- 文字列以外の値は無視される
- サイズは 1 MiB まで

例:

```json
{
  "locale.name": "Español",
  "settings.title": "Ajustes",
  "settings.save": "Guardar"
}
```

キー名は日本語版 (同梱の `ja.json`) と同じ名前を使います。

### 言語コード

- 英字 2〜3 文字で始め、`-` で区切った英数字を続けられます
  (例: `es`、`pt-BR`、`zh-Hant`、`zh-Hant-TW`)

## 日本語を書き換える

同じコードの言語ファイル (`ja`) を追加すると、同梱の日本語を上書きできます。
上書きしていないキーは同梱の日本語のまま表示されます。

## 注意

- 言語ファイルが読み込めない場合は日本語で表示されます
- 不正なファイル (JSON として読めない、`locale.name` が無い) は取り込まれません
- 取り込み前に内容が検証され、未知のキー・空文字・差し込み変数の不一致は警告されます
