固定ファイル名で公開された製品版は、リポジトリURLの末尾に
`/releases/latest/download/PawKemoViewer.exe` などを付けると直接取得できます。

## 更新方法

- **Windows / macOS / Linux**: 新しいインストーラーで上書きインストールします。
- **Android**: 新しい APK を上書きインストールします (同じ署名のためデータは保持されます)。
- **iOS / iPadOS**: 未署名 IPA のため、署名し直して導入します。

設定・フォロー・既読は端末内に残りますが、大きな変更の前には
[バックアップ](Files) を保存してください。

## 開発版

開発中のビルドは `debug-latest` プレリリースにあります。
デバッグビルドは診断ログと開発項目を含み、正式リリースとは構成が異なります。

## バージョンの見方

- 正式リリース: `0.5.7`
- デバッグビルド: `0.5.7+33 (abc1234)`。`+` 以降が GitHub Actions の実行番号で、
  APK のアプリ情報と Windows のインストーラー / プロパティにも同じ値が表示されます。
  括弧内は短い commit ID です
