## 更新方法

- Windows / macOS / Linux: 新しいインストーラーで上書きインストールします。
- Android: 同じ署名の新しい APK を上書きインストールします。データは保持されます。
- iOS / iPadOS: 未署名 IPA のため、署名し直して導入します。

大きな変更の前には[バックアップ](Files)を保存してください。

## 開発版

開発版は `debug-latest` プレリリースにあります。

- Windows / Linux / Android: 版番号ブランチへの push で更新。
- macOS / iOS: 手動ビルドのみ。
- プラットフォームごとに更新時刻が異なるため、ファイル名の版を確認してください。
- 診断ログと開発項目を含み、正式リリースとは構成が異なります。

## バージョンの見方

- 正式リリース: `0.5.8 (SHA)`
- 開発ビルド: `0.6.0+<commit-count> (abc1234)` のような形式。`+` 以降は git のコミット数で、全プラットフォームで同じです。
- 次の版は、不具合修正のみなら PATCH、機能追加なら MINOR を上げます。開発中はその番号で進め、リリース時に同じ番号になります。

## ファイル名

0.5.8 以降の正式版は、公開スクリプトにより `PawKemoViewer.exe` / `PawKemoViewer.apk` などの固定名で公開します。0.5.7 以前は `PawKemoViewer_0.5.7_x64-setup.exe` のような版入り名です。各リリースの実際のファイル名を確認してください。
