# 設定の一覧

設定はカテゴリに分かれています。表示や投稿の設定は変更するとすぐに反映されます。
セッションキーなど一部の項目は「保存」が必要です。

| カテゴリ | 主な内容 |
|---|---|
| アカウント | ログイン、ログイン状態、セッションキー (開発・診断) |
| 表示 | テーマ、レイアウト、投稿一覧の形式 |
| 言語・翻訳ファイル | 表示言語の選択、追加フォルダーの同期 |
| 投稿表示 | 低通信モード、省データ表示、外部メディアのプロキシ、cover.jpeg 除外 |
| 通信 | 通信タイムアウト |
| バックアップ | バックアップの保存・読み込み |
| キャッシュ | サムネイル上限、クリエイター索引、アイコンキャッシュ |
| 情報 | アプリ / サーバーのバージョン、実行プラットフォーム |
| 開発・診断 | 開発項目の表示、ログ、セッションキー、診断 (デバッグビルド) |

## アカウント

- **ID / パスワードでログイン**: ログインするとセッションキーが自動設定されます。
- **ログイン状態**: セッションの有効性をサーバーへ確認します
  (確認中 / ログイン済み / 未ログイン・無効 / 通信エラー)。
- **セッションキーの手動設定**: 通常のログインで問題がある場合に、
  pawchive.pw の Cookie の `session` 値を入力してテスト・保存します。

## 表示

- **テーマ**: ダーク / ライト。モバイルのアイコンもテーマに合わせて切り替わります。
- **レイアウトモード**: 自動 / デスクトップ / モバイル。
  自動は画面幅と端末に応じて切り替えます (768px が目安)。
- **投稿一覧の表示形式**: グリッド / リスト。
## 言語・翻訳ファイル

![モバイル版の言語設定。表示言語の選択と追加フォルダーの同期](https://www.nsmr0604.geek.jp/PawKemoViewer/assets/screens/ja-light-settings-mobile.png)

- **言語 / Language** で日本語、English、追加した言語を選べます。
- **言語フォルダーを同期** で追加フォルダーの変更を反映します。保存場所と JSON の作り方は [表示言語と翻訳ファイル](Languages) を参照してください。

## 投稿表示

- **低通信モード**: 新たな画像の取得を抑えます。保存済みの投稿サムネイルは表示できます。
- **省データのリスト表示**: 投稿内の画像を自動で読み込まず、ファイル名の一覧にします。
- **投稿の外部メディアを pkv プロキシ経由で読み込む**:
  元記事の URL を Referer に付けて外部メディアを取得します。
  外部サイトが記事からのアクセスだけを許可している場合に有効にします。
  pawchive 本体・API・画像サーバーは常に直接通信します。
- **FANBOX の cover.jpeg を除外**: 投稿詳細のファイル一覧から作品カバー画像を除外します。

## 通信

- **通信タイムアウト**: 既定 30 秒 (10 / 30 / 60 / 120 秒)。ログインにも同じ値を使います。
  応答が遅い環境では長めに設定します。

## バックアップ

設定・フォロー・既読を JSON に保存し、復元できます。
詳しくは [バックアップとログ](Files) を参照してください。

- **標準フォルダーに保存**: モバイルはアプリの `Documents/Backups` を更新します。
- **別の保存先を選ぶ**: 任意の場所へ保存します。
- **標準バックアップを開く / 別のバックアップを開く**: 復元します。
- **バックアップ JSON**: 貼り付けによる復元もできます (5 MiB まで)。

## キャッシュ

- **投稿サムネイルの保存上限**: 保存件数を選びます。超えた分は古い順に削除します。
- **クリエイター索引**: 件数・サイズ・最終取得を表示し、消去できます。
- **アイコンキャッシュ**: クリエイターアイコンの件数・サイズを表示し、消去できます。

## 情報

- アプリバージョン (デバッグビルドでは短い commit ID 付き)
- サーバーバージョン (確認ボタンで取得)
- 実行プラットフォーム
- 「開発・ログ項目を表示」: 製品版で開発・診断カテゴリを表示します (既定は非表示)。

## 開発・診断 (デバッグビルド)

デバッグビルドでは、ログの表示・書き出し、セッションキーの手動設定、
バックアップ JSON のダンプ、pkv の疎通テストが使えます。
正式リリースには含まれません。
