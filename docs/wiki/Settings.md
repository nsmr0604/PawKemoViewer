# 設定の一覧

設定はカテゴリに分かれています。表示や投稿の設定は変更するとすぐに反映されます。

| カテゴリ | 主な内容 |
|---|---|
| 表示 | テーマ、レイアウト、投稿一覧の形式 |
| 投稿表示 | 省データのリスト表示、AI 投稿と cover.jpeg の除外 |
| 言語・翻訳ファイル | 表示言語、追加フォルダーの同期 |
| 通信 | 低通信モード、User-Agent、通信タイムアウト |
| バックアップ | 保存、復元、JSON の貼り付け |
| キャッシュ | 投稿サムネイル、クリエイター索引、アイコン |
| アカウント | ログイン、ログイン状態、ログアウト |
| 情報 | アプリ / サーバーのバージョン、実行プラットフォーム、開発項目 |
| 開発・診断 | 診断ビルド、または情報で開発項目を有効にした場合だけ表示 |

## 表示

- **テーマ**: ダーク / ライト。モバイルのランチャーアイコンも同期します。
- **レイアウトモード**: 自動 / デスクトップ / モバイル。自動は画面幅と端末 UA で切り替えます。
- **投稿一覧の表示形式**: グリッド / リスト。

## 投稿表示

- **省データのリスト表示**: 投稿内画像を自動で読み込まず、ファイル名の一覧にします。
- **AI 投稿を除外**: ホームの一覧と検索結果から AI 分類を除外します。
- **FANBOX の cover.jpeg を除外**: 投稿詳細のファイル一覧と一括保存の添付候補から作品カバーを除外します(一覧カードのサムネイルには残ります)。

## 言語・翻訳ファイル

- **言語 / Language**: 日本語、English、追加した言語を選べます。
- **言語フォルダーを同期**: 追加フォルダーの変更を反映します。
- 不正なファイルは一覧に含めず、設定画面で理由を確認できます。

詳しくは[表示言語と翻訳ファイル](Languages)を参照してください。

## 通信

- **低通信モード**: 新たな画像の取得を抑えます。保存済みの投稿サムネイルは表示できます。
- **User-Agent**: 端末 / アプリ / Chrome。既定は端末で、互換性が最も高い設定です。
- **通信タイムアウト**: 10 / 30 / 60 / 120 秒。既定は 30 秒で、API とログインに使います。

## バックアップ

設定・フォロー・既読を JSON に保存し、復元できます。

- **標準フォルダーに保存**: モバイルは `Documents/Backups` を更新。
- **別の保存先を選ぶ**: 任意の場所へ保存。
- **標準バックアップを開く / 別のバックアップを開く**: 復元。
- **バックアップ JSON**: パネル内の貼り付けからも復元。

詳しくは[バックアップとログ](Files)を参照してください。

## キャッシュ

- **投稿サムネイルの保存上限**: 100 / 250 / 500 / 1,000 / 2,000 件。既定は 500 件。
- **クリエイター索引**: 件数・サイズ・最終取得を表示し、消去できます。
- **アイコンキャッシュ**: クリエイターアイコンの件数・サイズを表示し、消去できます。

## アカウント

- **ID / パスワードでログイン**
- **ログイン状態**: ログイン済み / 未ログイン・無効 / 通信エラー
- **ログアウト**: 確認後に実行

## 情報

- アプリバージョン
- サーバーバージョン
- 実行プラットフォーム
- **開発項目を表示**: 製品版で開発・診断カテゴリを表示します

手動 session は、情報 → 開発項目を表示 → 開発・診断 → 手動 session にあります。

## 開発・診断

診断ビルドでは最初から表示されます。製品版では情報の開発項目トグルで表示します。

- ログの表示・保存・消去
- 手動 session の入力・検証・保存
- 診断ビルドだけ: 詳細ログ、バックアップ JSON dump、pkv 疎通テスト、言語ファイル CRUD、iOS 外部ページ診断

製品版で開発項目を有効にしても、Full 診断のコードは有効になりません。
