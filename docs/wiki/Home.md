## PawKemoViewer とは

pawchive の投稿・クリエイター・お気に入りを閲覧するデスクトップ / モバイルアプリです。

| 項目 | 内容 |
|---|---|
| 対応 | Windows / Linux / macOS / Android / iOS・iPadOS |
| ログイン | 任意。ログインするとお気に入りとフォローが使える |
| データ | 設定・フォロー・既読・キャッシュは端末内に保存 |
| 配布 | GitHub Releases。iOS は未署名 IPA |

## 主な機能

- 投稿一覧（グリッド / リスト、無限スクロール、サービス絞り込み、AI 投稿の除外）
- クリエイター検索、プロフィール、タグ、投稿一覧、フォロー
- 投稿詳細（本文、画像・動画、コメント、改訂履歴、タグ、前後移動）
- フォロー中の新着、既読、投稿 / クリエイターのお気に入り
- 一括画像保存（本文・添付・外部リンク先、対象選択、進捗、中止、失敗理由）
- 外部ページ（全 OS）と、表示中画像のチェック式保存
- 低通信モード、投稿ファイルのリスト表示、サムネイルキャッシュ
- バックアップ、ログ、追加言語フォルダー
- ダーク / ライト、レイアウト切替、モバイルアイコンのテーマ連動

## プライバシー

- 開発者・配布者は、利用者の個人情報を一切収集しません。アクセス解析・広告・クラッシュ収集もありません。
- 設定・フォロー・お気に入り・既読・セッションキー・キャッシュは端末内にのみ保存され、機能提供のため pawchive.pw への通信にのみ使用されます。
- 詳細は[プライバシーポリシー](https://github.com/nsmr0604/PawKemoViewer/blob/main/docs/legal/privacy.ja.md)を参照してください。
