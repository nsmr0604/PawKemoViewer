# 困ったとき

## 投稿や画像が表示されない

1. 端末がインターネットに接続されているか確認します。
2. DNS フィルタ（AdGuard など）が `pawchive.pw` を遮断していないか確認します。遮断されている場合は、端末またはルーターの DNS を通常の DNS サーバーへ変更してください。
3. 設定 → 通信 → 通信タイムアウトを長め（60 秒など）にします。
4. 設定 → キャッシュでクリエイター索引やアイコンキャッシュを消去して再取得します。

## ログインできない

- ID / パスワードを確認し、通信タイムアウトを長めにします。
- 設定 → アカウントの **ログイン状態** で「通信エラー」か「未ログイン・無効」かを切り分けます。
- ブラウザで pawchive にログインできるか確認します。
- ログイン後のフォロー同期だけが失敗した場合も、ログイン画面が「通信エラー」と表示される既知の不具合があります。設定 → アカウントでログイン状態を確認してください。

## 外部サイトのリンクが開かない

- 外部ページが真っ白な場合は、投稿へ戻ってもう一度開いてください。
- サイト自体のリンク切れ・期限切れは、元記事を開いて確認してください。
- Linux では、初回取得時の Cookie が必要なサイトで表示が崩れることがあります。

## 元記事リンクが移動しない

本文内の FANBOX / Patreon の投稿 URL は、対応する pawchive 投稿へ移動します。「対応する投稿を確認できませんでした」と表示される場合は、まだ取り込まれていない可能性があります。「元記事を開く」から確認してください。

## 一括画像保存が失敗する

- 失敗理由が `HTTP 404` の場合、pawchive にサムネイルだけしかないことがあります。アプリはサムネイルを本体として保存しません。
- `HTTP 403` はサイト側の拒否です。User-Agent を「端末」に戻して再試行してください。
- iOS / iPadOS の一括保存は実機確認中です。失敗した場合はログと端末名・OS・アプリ版を記録してください。

## バックアップの読み込みに失敗する

- `pawkemoviewer-backup` 形式の JSON か確認します。
- サイズは 5 MiB までです。
- 復元は現在のフォロー・既読・設定を上書きします。必要なら先にバックアップを保存してください。
- `accountId` と `userAgentMode` は復元されません。

## 追加した言語が表示されない

- ファイル名が言語コード（例: `es.json`）になっているか確認します。
- `locale.name` があり、JSON として正しいか確認します。
- 追加の言語フォルダーに置き、**言語フォルダーを同期** を押します。
- 詳しくは[表示言語と翻訳ファイル](Languages)を参照してください。

## 設定画面の表示が崩れる

一部の Android 端末で、設定の項目名が細く潰れて表示されることがあります。設定を開き直すか、アプリを再起動すると正常に戻る場合があります。最新版でも再現する場合は、端末名・OS・アプリ版とスクリーンショットを記録してください。

## バージョンの確認

設定 → 情報のアプリバージョンで確認できます。開発版は `X.Y.Z+コミット数 (SHA)`、製品版は `X.Y.Z (SHA)` です。
