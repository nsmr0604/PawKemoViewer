# 困ったとき

## 投稿や画像が表示されない

1. 端末がインターネットに接続されているか確認します。
2. DNS フィルタ (AdGuard など) が `pawchive.pw` を遮断していないか確認します。
   遮断されている場合は、端末またはルーターの DNS を通常の DNS サーバーへ変更してください。
3. 設定 → 通信 → 通信タイムアウト を長め (60 秒など) にします。
4. 設定 → キャッシュ でクリエイター索引やアイコンキャッシュを消去して再取得します。

## ログインできない

- ID / パスワードを確認し、通信タイムアウトを長めにします。
- 設定 → アカウント の「ログイン状態」で「通信エラー」か「未ログイン・無効」かを切り分けます。
- ブラウザで pawchive にログインできるかも確認してください (アカウント自体の問題かどうか)。

## 外部サイトのリンクが開かない

- 外部ページが真っ白な場合は、投稿へ戻ってもう一度開いてください。
- サイト自体がリンク切れ・期限切れの場合は、元記事を開いて確認してください。

## 元記事リンクが移動しない

本文内の fanbox / patreon の投稿 URL は、対応する pawchive の投稿へ移動します。
「Pawchive で対応する投稿を確認できませんでした」と表示される場合は、
その投稿がまだ取り込まれていない可能性があります。「元記事を開く」から確認できます。

## バックアップの読み込みに失敗する

- ファイルが `pawkemoviewer-backup` 形式の JSON か確認します。
- サイズは 5 MiB までです。
- 読み込みは現在のフォロー・既読・設定を上書きします。必要なら先にバックアップを保存してください。

## 追加した言語が表示されない

- ファイル名が言語コード (例: `es.json`) になっているか確認します。
- `locale.name` が入っているか、JSON として正しいかを確認します。
- 追加の言語フォルダーにファイルを置き、設定 → 言語・翻訳ファイル の「言語フォルダーを同期」を押します。
- 詳しくは [表示言語と翻訳ファイル](Languages) を参照してください。

## 設定画面の表示が崩れる

一部の Android 端末で、設定の項目名が細く潰れて表示されることがあります。
設定を開き直すか、アプリを再起動すると正常に戻る場合があります。

## バージョンの確認

設定 → 情報 のアプリバージョンで確認できます。
